This is a web app I built using React, Vite, Tailwind CSS, and TypeScript. It lets developers click through different popular programming languages, frameworks, and tools to pick out and build a ideal tech stack.

<!-- techlonogy i used -->


Framework: React + Vite
Styling: Tailwind CSS
Language:TypeScript
State Management: React useState hooks
Toast Alerts: react-hot-toast library

<!-- what it does -->


I broke the project into separate reusable components like Navbar, Hero, TechStack, and Footer inside the src folder to keep the code clean.
 You can click on any tech card to add it in my stack, see my chosen items update live in the right sidebar, and can remove items or clear the whole list at once.
Every time you click a button to add, remove, or reset your choices, a toast notification pops up in the corner to confirm what just happened.
